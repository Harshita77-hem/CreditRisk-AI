How it works

  1. 1. Enter the profileEleven applicant, loan and credit-history fields go to the risk engine as they are.
  2. 2. The model scores itA trained model returns a default probability, compared with a fixed decision threshold.
  3. 3. Scenarios are re-scoredThe backend re-runs the same model on altered profiles for what-if and stress views.
  4. 4. The dashboard summarisesThis page only displays what the API returns. It calculates no risk itself.

About the model

CreditAI is a portfolio project. A pre-trained machine-learning classifier is served through a FastAPI backend, and this interface consumes the /risk-analysis endpoint.

This system provides machine-learning-based risk estimates for demonstration and decision-support purposes. Counterfactual and stress-test results represent hypothetical model scenarios and should not be interpreted as causal predictions or actual lending decisions. These scenarios are hypothetical model-based simulations and should not be interpreted as causal effects, financial advice, or guaranteed outcomes.
